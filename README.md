# 📚 مكتبة إسماعيل الثانوية

تطبيق تعليمي خفيف يتيح للطلاب والمعلمين الوصول إلى كتب المرحلة الثانوية بصيغة PDF بسهولة.

## 🎯 الهدف
توفير مكتبة منظمة وسريعة لكتب المرحلة الثانوية يمكن فتحها أو تحميلها من أي جهاز (هاتف أو كمبيوتر).

## 📌 المميزات
- 📚 عرض كتب جميع المواد الدراسية
- 🧭 تنظيم الكتب حسب المادة
- 🔍 البحث السريع داخل المكتبة
- 📖 قراءة الكتب مباشرة داخل الموقع
- 📥 تحميل الكتب بسهولة
- ⚡ واجهة بسيطة وسريعة وخفيفة

## 🏫 الفكرة
المشروع يهدف إلى تسهيل الوصول للمناهج الدراسية بدون تعقيد وبشكل مجاني وسريع.

## 🚀 الاستخدام
افتح الموقع ثم اختر الكتاب واضغط "فتح الكتاب".
