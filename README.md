# Ismail-Suliman-Hassan-platform-
مكتبة إسماعيل الثانوية تطبيق تعليمي خفيف يتيح للطلاب والمعلمين الوصول إلى كتب المرحلة الثانوية بسهولة. يوفر الكتب الدراسية بصيغة PDF مرتبة حسب الصف والمادة، مع إمكانية القراءة أو التحميل والبحث السريع. يتميز بواجهة بسيطة وسرعة في الأداء، ويهدف إلى دعم التعليم وتسهيل الحصول على المقررات الدراسية.
